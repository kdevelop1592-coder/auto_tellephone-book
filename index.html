📋 비상연락망 구축 시스템

Google Sheets + Apps Script · 구학반 데이터로 신학반 비상연락망 자동 구성

⚡ 실행 흐름

① 구학반 정보 입력
→
② 신학반 이름 입력
→
③ 메뉴 클릭
→
④ 자동 매칭 완료 ✅

📊 스프레드시트 열 구조

구분 구 학 반 (B~H) 신 학 반 (J~N)
열 B C D E F G H J K L M N
항목 구학반 번호 이름 집전화 학생 휴대폰 아버지 어머니 구학반 🔑 번호 🔑 성명 🔑 신학반 번호
입력 직접 입력 직접 입력
🔑 매칭 기준: J(구학반) + K(번호) + L(성명) — 3개 모두 일치해야 연락처가 복사됩니다.
✨ 스크립트 실행 시 새로운 시트('신학반_연락망')가 생성되어 연락처가 작성됩니다.

🛠 Apps Script 설치 방법

1
Google 스프레드시트를 열고 상단 메뉴에서 확장 프로그램 → Apps Script 클릭
2
기존 코드를 모두 지우고 code.js 파일의 내용을 전체 붙여넣기
3
Ctrl+S (또는 💾 저장 버튼) 으로 저장
4
스프레드시트 탭으로 돌아오면 상단에 📋 비상연락망 메뉴가 자동 생성됨
5
구학반 데이터와 신학반 이름을 입력한 후
📋 비상연락망 → 신학반 연락망 구축하기 클릭!

📌 함수 설명

onOpen() buildNewClassContactList()
함수명 역할
onOpen() 스프레드시트 열릴 때 상단 메뉴 자동 생성
buildNewClassContactList() 구학반 이름 기준으로 신학반 연락처 자동 매칭 후 기입. 미매칭 명단도 팝업으로 안내

💾 code.js 소스코드

코드가 길어져 복사 버튼을 누르면 전체 코드가 복사됩니다.
